## 🌌 Overview

**DHRUVA** is an avant-garde urban traversal platform engineered to transform mundane spatial navigation into an engaging, gamified epistemic odyssey. By unifying **Agentic LLM Oracles**, **Deterministic Safety Quantification**, and **Interactive 3D Spatial Computing**, Dhruva establishes an unrivaled paradigm in modern municipal exploration.

Traditional navigation apps reduce reality to sterile coordinates and uninspired shortest paths. Dhruva bridges discovery and security through a dual-state cognitive architecture: balancing **gamified quest-driven ludology** with **algorithmic, safety-first urban cartography**.

## 🧮 Mathematical Safety Formulation

Safety is quantified via a multi-parametric deterministic composite vector:

$$\mathcal{S} = \sum_{i=1}^{6} w_i \cdot \phi_i(x)$$

$$\mathcal{S} = w_1 \cdot \mathcal{C}_{\text{crime}} + w_2 \cdot \mathcal{L}_{\text{lux}} + w_3 \cdot \mathcal{D}_{\text{crowd}}(t) + w_4 \cdot \mathcal{R}_{\text{telemetry}} + w_5 \cdot \mathcal{E}_{\text{proximity}} + w_6 \cdot \mathcal{T}_{\text{transit}}$$

| Parameter | Coefficient ($w_i$) | Metric Description |
| :--- | :--- | :--- |
| $\mathcal{C}_{\text{crime}}$ | $0.25$ | Normalized inverse municipal crime density |
| $\mathcal{L}_{\text{lux}}$ | $0.15$ | Luminance & public lighting infrastructure index |
| $\mathcal{D}_{\text{crowd}}(t)$ | $0.15$ | Temporal footfall and pedestrian vitality coefficient |
| $\mathcal{R}_{\text{telemetry}}$ | $0.20$ | Decentralized verified explorer safety sentiment |
| $\mathcal{E}_{\text{proximity}}$ | $0.15$ | Spatial distance vector to emergency & medical infrastructure |
| $\mathcal{T}_{\text{transit}}$ | $0.10$ | Walkability score and pedestrian artery integrity |

## 🚀 Quickstart & Initialization

### Option A: Standalone Web App (Next.js / Vercel)
The web application is fully self-contained with built-in serverless routes and instant offline fallback datasets:

```bash
cd frontend-app
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

---

### Option B: Full-Stack with Python FastAPI Backend

#### 1. Backend Initialization
```bash
cd backend
python -m venv venv

# Windows:
.\venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

#### 2. Frontend Launch
```bash
cd ../frontend-app
npm install
npm run dev
```
