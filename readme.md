## 🌌 Architectural Paradigm

**DHRUVA** is an avant-garde urban traversal and geospatial intelligence platform engineered to transmute mundane spatial navigation into a hyper-engaging, gamified epistemic journey. Merging **Agentic LLM Oracles**, **Deterministic Safety Quantification Heuristics**, and **Immersive 3D Spatial Computing**, Dhruva establishes an unrivaled paradigm in modern municipal exploration.

Traditional navigation systems reduce reality to sterile coordinates and uninspired shortest paths. Dhruva resurrects the spirit of discovery through a dual-state cognitive architecture: balancing **gamified quest-driven ludology** with **algorithmic, safety-first urban cartography**.

## 🧮 Mathematical Safety Formulation

Safety is not treated as a vanity metric; it is synthesized via a multi-parametric deterministic composite vector:

$$\mathcal{S} = \sum_{i=1}^{6} w_i \cdot \phi_i(x)$$

$$\mathcal{S} = w_1 \cdot \mathcal{C}_{\text{crime}} + w_2 \cdot \mathcal{L}_{\text{lux}} + w_3 \cdot \mathcal{D}_{\text{crowd}}(t) + w_4 \cdot \mathcal{R}_{\text{telemetry}} + w_5 \cdot \mathcal{E}_{\text{proximity}} + w_6 \cdot \mathcal{T}_{\text{transit}}$$

Where:
* **$\mathcal{C}_{\text{crime}}$**: Normalized inverse municipal crime density.
* **$\mathcal{L}_{\text{lux}}$**: Luminance and public lighting infrastructure index.
* **$\mathcal{D}_{\text{crowd}}(t)$**: Temporal footfall and pedestrian vitality coefficient at time $t$.
* **$\mathcal{R}_{\text{telemetry}}$**: Decentralized sentiment-weighted citizen safety telemetry.
* **$\mathcal{E}_{\text{proximity}}$**: Spatial distance vector to nearest medical & emergency response infrastructure.
* **$\mathcal{T}_{\text{transit}}$**: Walkability score and pedestrian artery structural integrity.

## 🚀 Quickstart & Initialization

### 1. Repository Acquisition
```bash
git clone https://github.com/Asymptote-Horizon/Dhruva.git
cd Dhruva
```

### 2. Microservice Backend Initialization
```bash
cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 3. Spatial Frontend Launch
```bash
cd ../frontend-app
npm install
npm run dev
```

Navigate to `http://localhost:3000` to initiate the celestial walkthrough.
