# Dhruva UI Principles

## Design Language
- **Theme**: Dark cosmic + warm earthy accents
- **Primary**: #0a0a1a (deep space black)
- **Accent**: #bcd4ff (star blue) — inherited from Three.js intro
- **Warm**: #ff9f43 (amber/gold) — for XP, scores, highlights
- **Success**: #2ed573 (emerald) — safe zones
- **Danger**: #ff4757 (coral red) — unsafe zones
- **Surface**: #1a1a2e (card backgrounds)

## Typography
- Headings: 'Outfit', sans-serif (Google Fonts)
- Body: 'Inter', sans-serif (Google Fonts)
- Accent/Score: 'JetBrains Mono', monospace

## Animation Principles
- Entrance: fade-up with spring easing (Motion.dev)
- Cards: subtle scale on hover (1.02)
- Page transitions: slide + fade
- Loading: skeleton pulse with star shimmer
- No jarring animations — everything smooth and purposeful

## Component Design
- Cards: glassmorphism with subtle border
- Buttons: gradient fills with glow on hover
- Maps: dark theme tiles
- Chat: floating bottom-right panel with typing indicator

## Accessibility
- WCAG 2.1 AA contrast ratios
- Focus-visible outlines
- Reduced motion support
- Screen reader landmarks
