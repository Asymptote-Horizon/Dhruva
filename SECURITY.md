# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Dhruva, please report it via GitHub Security Advisories or contact the maintainers at `security@dhruva.dev`. All reports are acknowledged within 24 hours.
