# 🎙️ Dhruva Audio Repository

Place your narration audio files (.mp3, .wav, .m4a) here or inside `frontend-app/public/audio/`.

### Supported Formats
- MP3 (128kbps / 192kbps recommended)
- WAV / OGG

Files placed in `frontend-app/public/audio/` are automatically served via Next.js at `/audio/<filename>`.
